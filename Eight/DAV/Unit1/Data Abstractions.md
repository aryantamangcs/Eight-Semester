Data abstraction is the process of hiding complex, irrelevant details from the end users.
Just like in OOP.


## Why do we need Data Abstraction?

Real world datasets are huge.
So to reduce complexity and make better decisions, abstraction is used.

## Different Levels of Abstraction.

#### 1. View Level
This level of abstraction shows ***what information exists***
It doesn't show the internal implementation, it only tells what information exists.
We can only see the data, but it's implementation and where the data is stored is unknown to us.

#### 2. Logical Level
In Logical Level, not only can we view the data, we can also see the attributes, relationships between the elements.

 ERD(Entity Relationship Diagram) is an example of Logical Level.

#### 3. Physical Level
Data's physical storage.
It is concerned with how and where our data is stored.
Example:
- SQL database
- Cloud storage
- CSV file etc
