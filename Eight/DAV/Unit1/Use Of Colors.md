## What is Color?

Color is a visual encoding channel that is used to represent data, highlight important information, differentiate categories etc.

## Types of Color Usage?
There are three main ways that a color can be used in visualization.

#### 1. Categorical Colors (Qualitative Colors)
Colors are used to represent categories in visualization

For example

Gender 
Male -> Blue
Female -> Pink

Department
HR -> Blue
Development -> Green
Finance -> Red

#### 2. Sequential Colors 
Colors can be used to represent numerical or ordered data as well in visualization.

Marks
20 -> Light BLue
30 -> Medium Blue
50 -> Dark Blue

(We can see them in heat maps, temperature maps as well)

#### 3. Diverging Colors
Colors used when data has a meaningful midpoint

Loss -> One color
Neutral -> One color
Profit -> One color

if there was no neutral it will same as categorical colors but since we have a meaningful midpoint value it falls under diverging colors

## Color Properties
The three main important properties of colors are:

#### 2.1 Hue
Hue refers to the actual color.
Red,Green, Blue, Yellow etc

#### 2.2 Saturation
Saturation refers to the strength or purity of a color.

#### 2.3 Brightness
Brightness refers to how light or dark a color is


***Good color harmony

## Color Vision Deficiency (AKA Colorblind)

CVD is a condition where a person has difficulty distinguishing the colors due to absence or malfunctions of cones in retina.

***The human eyes have three types of cone cells:***
- Red-Sensitive Cones (L-cones) (responds to long wavelength colors)
- Green-Sensitive Cones(M-cones) (responds to medium wavelength colors)
- Blue-Sensitive Cones(S-cones) (responds to short wavelength colors)

***Red Green color deficiency is the most common color vision deficiency***

**Protanopia** -> Red-blind (Missing red-sensitive cones)
**Deuteranopia** -> Green-blind (Missing green-sensitive cones)
