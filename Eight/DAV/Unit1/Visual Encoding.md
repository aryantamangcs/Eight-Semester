Visual encoding is the method of converting data into visual elements. 
It is different from visual representation.

In Visual representation (we show the visual elements)
While
Visual Encoding (the way of converting numerical data , categorical data into visual elements)

## Components of Visual Encoding

#### 1. Marks
Marks are the basic geometric object used to represent data.

Point
Line
Area
Rectangle

etc are the marks used in visual encoding

#### 2. Channels
Channels are the visual properties of marks.

- Position
- Color
- Size
- Shape
- Angle
